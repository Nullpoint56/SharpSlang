- **Bound surface**: Slang's functions that the binding's own code calls, and the fields of its
  native structs that the idiomatic API reaches. A function is a vtable slot of one of Slang's
  COM-style interfaces, counted once on the interface that declares it, or a flat export of
  `SlangApi`; it is bound when code outside `dotnet/Native` calls it. Interfaces the host
  implements (`ISlangFileSystem`, `ISlangFileSystemExt`, `ISlangMutableFileSystem`, `ISlangSharedLibrary`, `ISlangSharedLibraryLoader`, `ISlangSharedLibrary_Dep1`, `ISlangWriter`) are not counted. A struct the public
  API takes or returns is exposed with all its fields; a struct the binding builds counts only the
  fields binding code reads or writes; a data layout no Slang function takes counts through
  its public type. Read from the built assemblies (IL and PDB).
- **Test coverage**: the lines of the hand-written C# that the suite executes, child processes
  included; the generated L0 (`dotnet/Native`) is not counted.
