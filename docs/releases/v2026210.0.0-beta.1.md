## Added
- SharpSlang: the binding over Slang v2026.21 (win-x64, linux-x64, linux-arm64), built from source with 22 patches, `docs/upstream.md`
- SharpSlang: Slang's reflection API, one member per `spReflection*` function but two
- SharpSlang: Slang's standard modules beside the compiler, `SessionOptions.ExperimentalFeatures` to import them
- SharpSlang.Descs: Slang's enums, structs and COM interface structs, no native code
- SharpSlang.Dxc: dxc copied from Microsoft.Direct3D.DXC 1.9.2609.5 on win-x64
- SharpSlang.Pipeline: baked shader packages and their reflection snapshot, read without the compiler
- SharpSlang.Pipeline.Bake: the reflection walk and the baker
- SharpSlang.Pipeline.NRI: the NRI pipeline projection, stored in a package at bake time
- osx-arm64 native library and symbols as zips on the release
